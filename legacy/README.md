# Legacy match AI (Python, 2013)

The first attempt at the Harpastum match simulation. `test.py` sets up an
11-a-side match on a 100 × 50 pitch and animates it with matplotlib. It needs
numpy, scipy and matplotlib.

The code does not run: `Pitch.py` imports a `Helper` module that is not in
the repo. The files are kept unchanged as a reference for the simulation's
design.
